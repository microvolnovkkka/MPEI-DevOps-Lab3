# Источник backend

Эта папка содержит копию отслеживаемых файлов репозитория
[nelkor/moscow-events](https://github.com/nelkor/moscow-events)
из коммита `157c5c86a7d2878adf5caccd742bb118e82f4482` (backend 1.0.0).

Оригинальные файлы, включая Dockerfile, код, SQL-миграцию, тесты, документацию
и лицензию MIT, перенесены без изменений. Служебная папка `.git` не копировалась.
Этот файл добавлен для указания происхождения кода.

Compose в корне лабораторной собирает backend через `build: ./backend`.
Dockerfile копирует приложение в образ и устанавливает его зависимости.
Каталог `.github` внутри этой папки является частью исходного снимка:
GitHub Actions нашего репозитория не запускает вложенные workflows.

Для обновления backend нужно явно заменить этот снимок, проверить совместимость
и обновить здесь номер коммита. Обычная сборка не скачивает репозиторий GitHub.
